# Pocket Ledger

Pocket Ledger — личный учёт финансов: TypeScript-библиотека и CLI-инструмент.

## Требования

- Node.js 24 и выше
- npm

## Установка

```bash
npm install
```

## Команды разработки

```bash
npm test        # запуск тестов (Vitest)
npm run typecheck  # проверка типов без сборки
npm run build    # сборка библиотеки и CLI в dist/
```

После `npm run build` CLI доступен как `node dist/bin.js` или через локальный bin
(`pocket-ledger`, если пакет установлен/связан глобально).

## Импорт банковской выписки CSV

Команда `pocket-ledger import <file.csv>` импортирует операции из CSV-файла
банковской выписки.

### Формат CSV

- Обязательные колонки (без учёта регистра, в любом порядке): `date`,
  `amount`, `description`.
- Необязательная колонка `currency` — если отсутствует, используется `RUB`.
- Разделитель (`,` или `;`) определяется автоматически по строке заголовка.
- Поддерживаются значения в кавычках, разделитель внутри кавычек и
  удвоенные кавычки (`""`) для экранирования, BOM и окончания строк LF/CRLF.
- Пустые строки пропускаются.

Дата принимается в формате `YYYY-MM-DD` или `DD.MM.YYYY` и всегда
проверяется как реальная календарная дата (например, `2024-02-30` — ошибка).
Сумма может использовать десятичную запятую и пробелы как разделители
тысяч (например, `"1 234,56"`); отрицательные суммы считаются расходом.

Пример файла:

```csv
date,amount,description,currency
2024-01-05,1000,Зарплата,RUB
06.01.2024,-250.50,Продукты,RUB
```

### Использование

```bash
pocket-ledger import statement.csv
```

В stdout выводится количество импортированных и ошибочных строк, а также
итоговые доход/расход/баланс. Подробности ошибочных строк (номер строки и
причина) выводятся в stderr — такие строки не прерывают импорт остальных
данных.

Коды выхода:

- `0` — импорт выполнен без ошибок строк;
- `1` — импорт выполнен, но есть строки с ошибками (детали в stderr);
- `2` — файл не удалось прочитать или в CSV отсутствует обязательная колонка.

## Категоризация операций

Правила категоризации описываются в JSON-файле (например, `rules.json`) как
массив объектов. Для каждой операции применяется **первое** правило,
удовлетворяющее всем указанным в нём условиям; если ни одно правило не
подошло, операции присваивается категория «Без категории».

Поля правила:

- `category` (обязательное) — название категории, непустая строка.
- `descriptionContains` — массив подстрок; правило подходит, если описание
  операции содержит **любую** из них (без учёта регистра).
- `descriptionRegex` — регулярное выражение (без учёта регистра),
  проверяемое против описания операции.
- `amountMin` / `amountMax` — включительные границы модуля суммы операции в
  рублях.

Все указанные в правиле условия объединяются через **И**. В правиле должно
быть задано хотя бы одно условие.

Пример `rules.json`:

```json
[
  { "category": "Еда", "descriptionContains": ["пятёрочка", "магнит"] },
  { "category": "Транспорт", "descriptionRegex": "такси|метро" },
  { "category": "Крупные покупки", "amountMin": 10000 }
]
```

## Месячный отчёт

Команда `pocket-ledger report <file.csv>` строит отчёт по расходам и доходам
за месяц на основе импортированной CSV-выписки и файла правил.

```bash
pocket-ledger report statement.csv
pocket-ledger report statement.csv --month 2024-01
pocket-ledger report statement.csv --rules my-rules.json
pocket-ledger report statement.csv --json
```

Опции:

- `--month YYYY-MM` — месяц отчёта. Если не указан, используется последний
  месяц среди валидных операций файла; если ни одной валидной операции нет,
  команда завершается с ошибкой (код `2`).
- `--rules path` — путь к файлу правил категоризации. По умолчанию
  используется `rules.json` в том же каталоге, что и CSV-файл.
- `--json` — вывести отчёт в формате JSON вместо таблицы.

Расходы группируются по категориям и выводятся по убыванию суммы (при
равенстве сумм — по алфавиту), с указанием количества операций и доли от
общего расхода за месяц (округление до 0.1%, без принудительной подгонки
суммы долей к 100%).

Пример табличного вывода:

```
Месяц: 2024-01
Доход: 1000.00
Расход: 400.50

Категория       Сумма   Доля  Кол-во
Еда            250.50  62.5%       1
Транспорт      100.00  25.0%       1
Без категории   50.00  12.5%       1
```

Пример вывода с `--json`:

```json
{
  "month": "2024-01",
  "income": 1000,
  "expense": 400.5,
  "categories": [
    { "category": "Еда", "amount": 250.5, "count": 1, "share": 62.5 }
  ]
}
```

Строки CSV с ошибками выводятся в stderr так же, как в `import`, и не
включаются в отчёт (отчёт строится по валидным строкам).

Коды выхода:

- `0` — отчёт построен без ошибок строк CSV;
- `1` — отчёт построен, но есть строки CSV с ошибками (детали в stderr);
- `2` — не удалось прочитать CSV-файл, файл правил, определить месяц отчёта
  или переданы некорректные аргументы командной строки.

## Текущее состояние

- Библиотека экспортирует базовые утилиты (`getVersion`, `APP_NAME`), общие
  типы и функции учёта (`Transaction`, `parseAmount`, `summarize`,
  `formatAmount`), импорт CSV (`importCsv`), категоризацию (`categorize`,
  `parseRules`) и построение месячных отчётов (`monthlyReport`) из
  `src/index.ts`.
- CLI (`src/bin.ts`) поддерживает `--help`, `--version`, `import <file.csv>`
  и `report <file.csv>`.
