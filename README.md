# Pocket Ledger

Pocket Ledger — личный учёт финансов: TypeScript-библиотека и CLI-инструмент.

## Требования

- Node.js 24 и выше
- npm

## Установка

```bash
npm install
```

## Команды разработки

```bash
npm test        # запуск тестов (Vitest)
npm run typecheck  # проверка типов без сборки
npm run build    # сборка библиотеки и CLI в dist/
```

После `npm run build` CLI доступен как `node dist/bin.js` или через локальный bin
(`pocket-ledger`, если пакет установлен/связан глобально).

## Текущее состояние

Проект находится на стадии начального каркаса:

- Библиотека экспортирует базовые утилиты (`getVersion`, `APP_NAME`) из `src/index.ts`.
- CLI (`src/bin.ts`) поддерживает `--help` и `--version` и явно сообщает,
  что остальной функционал ещё не реализован.
- Импорт CSV, категоризация операций, отчёты и бюджеты **не реализованы** —
  форматы и правила для них ещё уточняются.

## Планируемые возможности

- Импорт транзакций из CSV
- Автоматическая и ручная категоризация операций
- Отчёты по расходам и доходам
- Бюджеты по категориям и периодам

Эти возможности будут добавляться в следующих итерациях после уточнения
требований и форматов данных.
